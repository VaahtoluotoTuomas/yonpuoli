# Historical audit material

This directory preserves the original July 2026 audit inputs, evidence, reports
and remediation plans. They are intentionally public: they show how findings were
challenged, corrected and closed. Their paths, severity counts and repository
snapshots describe the audit date, not the current Yönpuoli release candidate.

Read [`../README.md`](../README.md) first for the active decision layer and
[`../../PLAN.md`](../../PLAN.md) for current release status.

## Contents

- `prompts/` — original audit and independent-evaluation assignments;
- `COCOQUANTUS_FIDELITY.md` — lineage and interpretation analysis;
- `EXECUTIVE_SUMMARY.md`, `FINDINGS.md`, `FEATURE_TRACEABILITY.md` — first-pass
  reports, including severity classifications later refined by evidence;
- `TEST_EVIDENCE.md` — commands, environment and results captured at audit time;
- `REMEDIATION_ROADMAP.md`, `GUI_DEVELOPMENT_PLAN.md` — completed implementation
  plans superseded by the current roadmap;
- `IMPROVEMENT_BACKLOG.md`, `LISTENING_TEST_PROTOCOL.md` — historical proposals
  and acceptance protocol.

Historical prose may refer to files by their former paths. Git history is the
authority for reconstructing the exact audit tree.
