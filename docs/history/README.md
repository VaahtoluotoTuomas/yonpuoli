- [`PLAN_nocturne.md`](PLAN_nocturne.md) — koko Nocturne/Night-, Audio-, soak-,
  playability- ja release-content-vaiheen toteutusjournal.

  muuttuva agenttihandoff; nykyinen juuren `CLAUDE.md` sisältää vain vakaat säännöt.
- [`manual_checklist_nocturne.md`](manual_checklist_nocturne.md) — suoritetut
  kuuntelu-, hardware-, GUI- ja pitkäajoprotokollat.

  GUI-vaiheen hyväksyntäprotokolla.

Historiallisissa raporteissa olevat commit-, testi- ja riviviitteet kuvaavat omaa
ajankohtaansa. Uusi julkaisupinta ei muuta niiden tulosta jälkikäteen.
